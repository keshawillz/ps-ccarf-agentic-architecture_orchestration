[page 1]
Escalate to a human agent when the customer explicitly asks for one. Do not
attempt to resolve the issue first. Honor the request immediately.

[page 2]
Escalate when policy does not address the customer's situation. A policy gap
is not the same as a difficult case. Difficult cases within policy should be
resolved by the agent.

[page 3]
Every escalation must include the customer ID, the root cause as understood
so far, any amounts involved, and a recommended action. The receiving agent
cannot see the conversation transcript.
